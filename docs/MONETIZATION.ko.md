# 광고·Plus·비용 제어

## 상품

우리의 공간 Plus: 월 4,900원, 연 39,900원. 상품 ID는 `com.interest.couplediary.plus.monthly` / `com.interest.couplediary.plus.yearly`. Apple 서버에서 검증된 유효 기간으로 현재 커플 두 사람의 사진 업로드와 광고 제거를 제어한다. 연결 해제로 Apple 구독 자체가 자동 해지되지는 않는다.

무료 텍스트 기록은 유지한다. 유료 기간이 끝나도 기존 사진 조회와 사진이 포함된 일기의 텍스트 수정은 가능하다. 신규 사진 부착은 서버가 거부한다. 별도 웹 PG는 이번 iOS 복구 범위에 포함하지 않는다.

## 광고

개발 빌드는 Google 공식 iOS 테스트 앱·배너·전면 광고 ID를 사용한다. 저장 3회 이후, 최소 10분 간격, 하루 최대 2회의 전면 광고 기회를 예약한다. 저장 완료 후 달력 화면이고 모달이 없고 앱이 보이며 동의를 확인한 경우에만 노출한다. 전면 광고의 실제 소재가 항상 동영상인 것은 아니며 AdMob이 결정한다. 광고 오류가 일기 저장을 막지 않는다.

2026-11-14 AdMob에서 기존 iOS 앱과 배너·전면 광고 단위의 소유권 및 ID 일치를 확인했다. 앱은 스토어 미연결·심사 필요·송출 제한 상태다. 네이티브 앱 ID는 실제 계정 ID로 맞췄지만 광고 단위는 공식 테스트 ID를 유지한다. 실광고 빌드는 VITE_ADMOB_LIVE_ADS=true로 명시적으로 빌드하며 승인·실기기 검증 전에는 활성화하지 않는다. AdMob 계정의 지급·세금 정보를 변경하지 않았다. 공식 안내: https://developers.google.com/admob/ios/test-ads

## 비용 구조

- Cloud Functions v2: minInstances=0, maxInstances=2, 256MiB, CPU gcf_gen1, concurrency=1. 유휴 인스턴스를 예약하지 않는다. 시작 지연은 있을 수 있다.
- 매시간 한 번의 정리 작업과 최대 200개 삭제. 정리 대상은 만료 후 24시간 지난 미부착·제거 사진과 만료 초대. 가득 찬 배치 로그를 감시하고 적체가 생기면 처리 용량을 조정한다.
- 원본을 서버로 보내지 않고 1,440px JPEG로 다시 인코딩해 EXIF/GPS 메타데이터를 제거한다. 목표 256KiB, 상한 512KiB. HEIC 직접 디코딩은 아직 지원하지 않는다.
- 커플을 바꿔도 초기화되지 않는 계정 단위 일 6회·월 90회 업로드 예약. 최대 2인 × 90장 × 512KiB = 커플당 월 신규 사진 90MiB 상한(실제 목표 크기 기준 45MiB). 보관 중인 사진은 누적된다.
- 표시 근처의 사진만 인증된 Blob으로 읽고 메모리 캐시를 최대 64MiB로 제한한다. 앱 재시작 이후 영구 캐시는 없으므로 반복 조회에 전송 비용이 생길 수 있다.
- 최근 100개 일기부터 조회하고 필요할 때 더 읽는다. JSON 전체 내보내기는 전체 기록 읽기 비용이 발생하며 사진 파일을 포함하지 않는다.

Firebase Blaze/결제 계정, Storage·Firestore·Functions·빌드·Scheduler 등 사용량에 따른 비용이 발생할 수 있다. maxInstances와 예산 알림은 청구 금액을 강제로 차단하는 기능이 아니다. 스테이징에서 사용량을 측정하고 예산 알림·App Check·남용 방지·로그 보관을 출시 전에 설정해야 한다. 요금은 지역과 계정별로 달라 여기서 0원이나 정액 유지비를 보장하지 않는다.

공식 실행 옵션: https://firebase.google.com/docs/functions/manage-functions

## 후속 비용 보호

계정별 쓰기 120회/분·1,000회/일, 공간 생성 10회/일·초대 생성 20회/일 제한을 추가했다. `DIARY_WRITES_ENABLED`와 `PHOTO_UPLOADS_ENABLED` 중지 옵션은 서버 재배포 후 적용된다. 월 10,000원 예산 알림은 사용자 선택 기준이며 운영 프로젝트에 실제 생성·재조회했다. 스테이징 결제 연결 후 운영·스테이징 두 프로젝트를 예산 필터에 포함했다. [운영 절차](FIREBASE_OPERATIONS.md)를 따른다.

## App Store Connect 등록 및 스테이징 결제

월간 6834702626(4,900원), 연간 6834705789(39,900원) 상품을 기존 그룹 22577704에 등록했다. 한국어 이름·설명과 판매 지역을 설정했고 연간은 1년분 일시 결제로 구성했다. 스테이징의 billing-enabled.cjs는 diary/accountDeletion/appleBilling/appleNotifications만 내보내며 Scheduler를 제외한다. Apple 개인 키는 승인받아 Secret Manager에 저장했다. 테스트 구매는 Sandbox이며 운영 과금은 운영 서버와 App Store 심사·출시가 필요하다. 구매 활성화·계정 토큰 발급·위조 결제 거부 검사는 통과했으나 실제 StoreKit 구매/복원·사진 업로드는 아이폰 검증 대기다. Sandbox 알림 URL은 저장했지만 Apple 테스트 알림 API는 4040007을 반환해 전송 검증이 남았다.
