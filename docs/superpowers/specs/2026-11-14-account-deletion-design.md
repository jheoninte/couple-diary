# 계정 삭제와 운영 정책

사용자 승인: 출시 작업 순서대로 실행. 운영자 COMINO, 문의 cs@comino.app. 구현을 간소화하기 위해 수동 삭제 선호.

Apple 안내(https://developer.apple.com/help/app-review/guideline-reference/5-1-1-account-deletion): 앱 안에서 삭제 요청을 시작할 수 있어야 한다. 이메일 발송만을 필수 경로로 두면 안 된다. 수동 처리는 허용되지만 처리 기간과 완료 알림을 제공해야 한다.

선택: 앱 내 최근 비밀번호 재인증 → 삭제 영향/구독 안내 → 명시적 요청 → 공유 중단 및 접근 차단 → COMINO가 전용 CLI로 실제 삭제 → 완료 상태와 이메일 알림 처리. 처리 목표 7일 이내는 구현 기본값이다. 이메일 전용 접수와 상시 자동 작업은 선택하지 않았다. 외부 메일은 자동 발송하지 않는다.

자기 계정의 현재·과거 일기, 사진, 댓글, 좋아요, 설정, 초대, 업로드 예약, 프로필, Auth 계정을 지운다. 상대방 작성 기록은 보존하며 공유 중단 후 자기 기록만 보관함에서 읽는다. 오래된 알 수 없는 스키마는 원본을 손상하지 않고 관리자 검토를 요구한다. 앱 접근은 요청 즉시 차단한다. StoreKit 구독은 자동 해지되지 않음을 알리고 Apple 구독 관리 링크를 제공한다.

실제 삭제는 관리자 CLI가 기본 미리보기로 동작하고 --execute --confirm UID를 함께 지정해야 수행한다. 프로젝트를 명시하고 로컬 테스트와 운영을 분리한다. 페이지 단위 삭제 상태를 저장해 실패 시 재개한다. 완료 증명은 개인정보 없는 임의 접수번호로 30일 조회한다. 이메일은 완료 알림을 위해 잠시 보관하고 알림 처리 후 제거한다. 접근 차단 표식은 기존 토큰과 지연된 결제 알림 재생성을 막는다.

개인정보 문서는 확정 가능한 수집 목적·종류·문의처·삭제 절차를 반영하되, 실제 Firebase 저장 위치와 국외 이전·백업 보관·광고 계정 설정은 확인 전 출시 초안 표시를 유지한다.
