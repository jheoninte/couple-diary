# 2026-11-14 UI 개선

인스타그램과 에어비앤비의 명확한 위계·간결한 카드·넓은 여백을 참고해 커플 일기장의 기존 기능을 유지하면서 시각 체계를 정리했다. 흰색 표면, 진한 글자, 라즈베리 포인트, 12~24px 모서리, 최소 44px 핵심 터치 영역을 사용한다. 홈의 글쓰기 행동을 강조하고 기록 카드의 작성자·날짜·내용·반응을 분리했다. 로그인/복구·초대·설정·Plus·온보딩에도 같은 분위기를 적용했다. 외부 Google 폰트 의존성을 제거하고 시스템 글꼴을 우선 사용한다.

로그인 혼합 SDK 수정과 외부 Firebase 모듈 잔존 검사도 포함한다. 구문 검사, 단위 검사 54개, 스테이징 빌드 및 실제 아카이브 번들 검사를 통과했다. 배포 파일로 스테이징 리뷰 계정 로그인·두 사람 기록·댓글 조회를 확인했다. 동일한 배포 파일의 새 회원가입 화면에서도 실제 스테이징 가입과 연결 화면 진입을 확인했다. iPhone 자체의 동작은 TestFlight 설치 후 재확인이 필요하다.

리뷰 계정 두 개는 스테이징 전용이며 서로 연결돼 있다. 이메일 확인 상태와 가상의 일기 2개·댓글 1개를 준비했고 비밀번호 로그인 검증을 마쳤다. 비밀번호는 소스/문서에 저장하지 않는다. 운영 서버로 전환하면 같은 계정이 자동으로 이전되지 않는다.

사용자 요청대로 백업 작업은 실행하지 않았다.
